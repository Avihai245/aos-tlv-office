# QA report, 2026-11-13

Checks run for the luxury redesign (serif headlines, warm palette, champagne gold) and the included meeting-room hours on office pages.
The site was built in production mode against a local stand-in for the Supabase API that served the live catalogue rows.

| # | Check | Result | How it was verified |
|---|---|---|---|
| 1 | Design on every page | Pass | Desktop (1440 px) and phone (390 px) screenshots of home (he, en), rooms, room, offices, office, membership, account, password, documents, both landing pages, booking status and 404. |
| 2 | Flows and buttons | Pass | Playwright walk on desktop and phone: 23 pages return the right status with one `h1` and no horizontal scroll; FAQ, hero tabs, mobile menu, accessibility panel, booking widget (day → package → slot → summary), empty contact form refused, language switch; no console errors. |
| 3 | Speed | Pass | Lighthouse mobile, three runs each against `main`: home 92–94 (main 93–95), LCP 3.0–3.3 s (main 2.9–3.2 s), CLS 0.004 on both. The headline serif adds three small font files; dropping the unused Plex 500 weight takes two off. |
| 4 | Accessibility, SEO, best practices | Pass | Lighthouse 100/100/100 on home, room, offices, office, membership, privacy. Landing pages, account and booking pages are `noindex` on purpose. |
| 5 | User isolation (RLS) | Pass | RLS on every public table; `anon` reads only the catalogue (settings, rooms, hours, packages, visible offices). Every user RPC checks `auth.uid()` ownership and every admin RPC checks `private.is_admin()`. Image uploads: admins only, JPEG/PNG/WebP, 5 MB. |
| 6 | Included meeting-room hours | Pass | The office page line comes from `offices.free_hours` and is shown once even when the same text is also typed in the office's list. The FAQ, `llms.txt`, the office meta description and the office structured data (`additionalProperty`) carry the same fact. |

## Still open

  `update public.offices set amenities_he = array_remove(amenities_he, 'חדר ישיבות ל־3 שעות במסגרת השכירות'), amenities_en = array_remove(amenities_en, '3 hours of the meeting room included in the rent');`
